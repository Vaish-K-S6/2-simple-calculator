Simple Calculator

A simple calculator application built using **Python** and a **Web version** with HTML, CSS, and JavaScript.

This project is part of my daily mini-project series.

---
Live Demo
🔗 https://vaish-k-s6.github.io/2-simple-calculator/

--

Python Version
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero

Web Version
- Button-based calculator UI
- Supports +, −, ×, ÷ operations
- AC (All Clear) button
- C (Clear last digit) button
- Clean and simple design
